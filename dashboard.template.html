Metric definitions, source & limitations

Source: Sapphire IQ project materials, “Amazon Sales Data India.xlsx”, Sheet1. All 10,000 original records and 13 fields are embedded in this file. No records were removed. Source period: . This is an educational dataset; it has not been verified as actual Amazon operating data.

  • Booked sales = SUM(Total_Sales_INR). Recorded profit = SUM(Profit_INR). Discount is already reflected in source sales; it is not deducted again.
  • Orders = distinct Order_ID (all IDs are unique in this source). Units = SUM(Quantity). Average order value = booked sales / orders. Profit margin = recorded profit / booked sales.
  • Delivered sales = booked sales restricted to Delivered. Returned and cancelled orders retain positive source sales but zero recorded profit. No net-revenue estimate is fabricated.
  • Return rate = returned orders / orders in the filtered scope. Cancellation rate follows the same rule. Every chart, table, KPI and CSV export uses the same filters.
  • Rates and margins display “—” when no denominator exists. Latest partial months are not annualized. No causal conclusions are supported by this dataset.

Initial source checks: 10,000 unique order IDs; zero missing cells; no exact duplicate records; valid ISO dates. Source workbook is preserved unchanged in the project package. Analysis is computed in the browser from source rows; no spreadsheet formulas or external chart libraries are required.
